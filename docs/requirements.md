# 実装要件

## メディアの全画面表示

- X の画像または動画を拡大表示したとき、「全画面表示」ボタンを表示する。
- ボタンを押したとき、表示中の X カラムを Fullscreen API により全画面表示する。
- 全画面表示中は X のヘッダーバーと TwitamaModoki の下部タブバーを表示しない。
- 全画面表示中のボタンは「全画面解除」とし、押すと通常表示へ戻す。
- 画像・動画の拡大表示を閉じたとき、TwitamaModoki が開始した全画面表示を解除する。
- ブラウザ標準の操作で全画面表示を解除した場合も、通常表示へ復帰する。
- Fullscreen API が未対応の環境では「全画面表示」ボタンを表示しない。
- ブラウザUIが表示されたままでもコンテンツが表示領域外へはみ出しにくいよう、動的ビューポート高を使用する。
