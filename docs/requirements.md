# 実装要件

## メディアの全画面表示

- X の画像を拡大表示したとき、または動画を再生したとき、「全画面表示」ボタンを表示する。動画を一時停止しても表示中はボタンを維持し、動画が閉じられる、表示領域外へ移動する、別の画面へ遷移する、または再生終了したときにボタンを隠す。
- ボタンを押したとき、表示中の X カラムを Fullscreen API により全画面表示する。
- 全画面表示中は X のヘッダーバー、TwitamaModoki のレート制限パネルと下部タブバーを表示しない。
- 全画面表示中のボタンは「全画面解除」とし、押すと通常表示へ戻す。
- 「全画面解除」ボタンは全画面表示の開始または画面操作から 3 秒後に自動的に隠し、画面をタップ、ポインター操作、またはキー操作したときに再表示する。
- 画像・動画の拡大表示を閉じたとき、TwitamaModoki が開始した全画面表示を解除する。
- ブラウザ標準の操作で全画面表示を解除した場合も、通常表示へ復帰する。
- Fullscreen API が未対応の環境では「全画面表示」ボタンを表示しない。
- ブラウザUIが表示されたままでもコンテンツが表示領域外へはみ出しにくいよう、動的ビューポート高を使用する。
